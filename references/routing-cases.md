# 请求类型与边界

按用户意图选择输出，不让技法需求覆盖权限和篇幅。

| 请求 | 路由与关键约束 |
|---|---|
| 用这个 skill 写约一万二千字小说，给出题材与人物 | 原创写作，内部设计整篇时间与详略，交完整稿 |
| 写得像马尔克斯一点，原情节不改，不加超自然 | 轻改或限定重构，分别增强结构和节奏，锁定情节 |
| 流水账，没孤独和时间感，只给建议 | 诊断，用正文证据定位层面，不直接重写 |
| 句子绵长一些，情节保留 | 强化语言节奏，检查中段；不以增加记忆事实充数 |
| 六十字以内写一个人等亲人 | 微型场景，直接成稿，实际计数，不附提纲 |
| 只有一个题材，先构思不要写正文 | 构思，给关系与时间的可落笔结构 |
| 家族三代，名字和习惯形成回声 | 长篇设计，谱系与变奏按需使用 |
| 已经知道他会死，重构为反悬念 | 重构，明确谁知道、谁误判，保留具体因果 |
| 参考这几本书，但不要全扫描 | 有限抽样，归纳方法，不装入原著正文 |
| 搜集网上马尔克斯金句 | 来源核验，短引与译意分开，不用合集替代出处 |
| 模拟马尔克斯与我讨论写作 | 文学模拟，首次说明性质，保持事实边界 |

普通游戏魔法、超现实图片、作者获奖年份、合同、商业汇报和技术说明不隐式触发。若明确点名本 skill，服从当前任务，并简短说明它能帮助的部分。

“更有魔幻感”“时间不线性”“家族史”需结合上下文判断：现实题材文学可以使用；游戏系统、物理问题、族谱数据不自动转为小说。
