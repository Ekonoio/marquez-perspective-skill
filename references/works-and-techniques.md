# 作品差异与机制选择

把此表当作高层次教学归纳，不称作作者唯一写法。只按当前题材选择主导机制。

| 作品 | 可迁移的方法 | 避免的简化 |
|---|---|---|
| 《百年孤独》 | 家族行为的代际变奏，过去持续作用，叙述者回望，现实与异常的平静并存 | 所有故事都要族谱、鬼魂、预言 |
| 《一桩事先张扬的凶杀案》／上传题名《一桩事先张扬的谋杀案》 | 已知结果，回到同一天，矛盾证词，阻止失败的具体节点 | 侦探找凶手；命中注定省略因果 |
| 《没有人给他写信的上校》 | 等待消耗今天，日常重复的成本，尊严与生存冲突，结尾承受长期压力 | 增加魔幻；复制末句的粗口 |
| 《霍乱时期的爱情》 | 身体与衰老，执念被漫长生活改写，爱情中的不通达 | 只写浪漫誓言或等待年数 |
| 《族长的秋天》 | 声音流动，权力的循环与隔绝，过量叙述 | 单靠超长句制造威严 |
| 《枯枝败叶》 | 同一事件的多重意识，地方记忆与排斥 | 普通线性家族介绍 |
| 《迷宫中的将军》 | 公共神话与衰败身体的摩擦 | 把历史人物神化 |
| 短篇魔幻叙事 | 异常的日常后果，不同知识体系的摩擦，实用反应 | 奇观与魔法说明书 |

## 选择方式

从人物正在承受的压力出发，而非先选道具：等待可以选耗损与省略；已知死亡可以选责任与证词；家庭错位可以选称谓、家务与私人时间；集体否认可以选档案与流言。

为主导机制选择一个现实支点，再按需要加入语言、关系或历史的辅助方法。若某个特征只能通过移植原作道具显现，删掉它。句子可以绵长而无超自然，日常可以克制却有深时间；结构强度不等于魔幻数量。
